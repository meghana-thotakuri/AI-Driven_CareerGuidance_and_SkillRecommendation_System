# CareerCraft: Transformer-Driven Skill Recommendation and RAG-Powered Career Advisory System

## About
CareerCraft is an AI-powered career guidance system for students and professionals. Users enter their education, skills, certifications, experience and career preferences. The system finds the skills they are missing, recommends suitable careers, and gives a personalized learning roadmap.

## Features
- Skill gap analysis: compares the user's skills with the skills needed for a career
- Semantic search: finds relevant career information by meaning, not just keywords
- RAG-based career advisor: gives personalized advice using retrieved knowledge and a Large Language Model (LLM)
- Career recommendation with a match score
- Personalized learning roadmap (skills, courses, certifications)

## How It Works
User Profile -> Profile Analysis -> Skill Gap Analysis -> Semantic Retrieval -> RAG Framework -> Career Recommendation -> Learning Roadmap

## Technologies Used
- Frontend: HTML, CSS, JavaScript
- Backend: Python (Flask / FastAPI)
- AI/ML: Transformer Models (Hugging Face), Retrieval-Augmented Generation (RAG), Large Language Models (LLMs)
- Vector Database: FAISS / Pinecone
- Tool: VS Code

## Example Output
- Missing Skills: Transformer Models, Vector Databases, MLOps
- Recommended Role: Machine Learning Engineer (Match Score: 85%)
- Learning Path: Transformer Models -> Hugging Face -> Vector Databases -> RAG Applications -> MLOps
